# gadam.kz
Qadam — образовательная платформа Казахстана, где каждый может найти подходящие курсы, репетиторов и кружки в одном месте. Мы помогаем ученикам получать новые знания, родителям находить занятия для детей, а преподавателям — делиться опытом и находить учеников. Наша цель — сделать образование доступнее и помочь каждому найти свой путь к успеху.
